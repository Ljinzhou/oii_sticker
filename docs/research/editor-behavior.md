# 主流 Markdown 编辑器操作方式调研报告

> 2026-08-15 · 多 agent 并行调研（Notion / Obsidian / Typora，均基于官方文档实测抓取 + 使用经验），
> 用于 oii_sticker 即时预览编辑器"复刻主流编辑器操作方式"的需求分析。

## 一、三类编辑器定位

| 编辑器 | 核心模型 | 代表交互 |
|---|---|---|
| **Typora** | 纯 WYSIWYG：文档即渲染视图 | 标记输入即转换、光标移入渲染元素自动展开源码、专注写作 |
| **Obsidian** | 双模式：源码 + Live Preview（CodeMirror 6 内核） | 行内标记渲染、光标穿越语法标记、命令面板、多光标 |
| **Notion** | 块模型（Block）：非严格 Markdown | 斜杠命令创建/转换块、拖拽手柄、块菜单、浮动工具条 |

## 二、操作方式共识（复刻必做清单）

### 1. 标记输入与自动转换（三者一致）
- **行内标记闭合即渲染**：`**x**`、`*x*`、`` `x` ``、`~~x~~`、`$x$` 输入闭合标记的**瞬间**渲染为样式
- **块级标记行首输入 + 空格/回车触发**：
  - `#`×1-6 + 空格 → 标题；`-`/`*`/`+` + 空格 → 无序列表
  - `1.` + 空格 → 有序列表；`- [ ]`/`- [x]` + 空格 → 任务
  - `>` + 空格 → 引用（Notion 例外：`>` 是折叠列表、引用用 `"`）
  - `---`/`***` + 回车 → 分隔线；``` ``` ``` + 回车 → 代码围栏（自动闭合）
  - `$$` + 回车 → 公式输入区；`|表头|表头|` + 回车 → 表格（自动补分隔行）
- **自动配对**：`**`、`*`、`` ` ``、`$` 自动配对；选中文本输入标记字符 → 自动包裹

### 2. 渲染元素中的光标行为（Typora/Obsidian 核心细节）
- **光标移入行内渲染元素（粗体/斜体/代码/链接/公式）中间或边界 → 元素展开为源码**，便于修改标记；移出后恢复渲染
- 光标"穿越"隐藏的语法标记（在渲染文本中左右移动，标记不可见）
- 选择跨越标记时标记临时显示（如 Ctrl+A 全选全部显示）
- 块级标记（`#`、`- [ ]`、`>` 等）在光标位于块内时显示，否则隐藏

### 3. 回车 / Tab / 退格行为
- **Enter**：列表/引用内回车 → 自动续接同类型标记；连续两次回车（或空项回车）→ 退出列表/引用；标题行尾回车 → 下一行转普通段落；标题中间回车 → 标题断开
- **Shift+Enter**：软换行（不产生新块）
- **Tab**：列表内 → 嵌套缩进（Shift+Tab 取消嵌套）；代码块内 → 缩进；表格内 → 下一单元格
- **Backspace**：空列表项行首退格 → 退出列表；块开头退格 → 与上一块合并

### 4. 代码块 / 公式块 / 表格（编辑细节）
- **代码块**：围栏 ` ```lang ` 指定语言即高亮；语言可点击/右下角修改；Tab/Shift+Tab 缩进；行号可开关；Ctrl+Shift+K 创建；光标在块内 Ctrl+A 全选整块；点击块外退出
- **公式块**：`$$` + Enter 进入 TeX 输入区，**输入过程实时预览**；↑/↓ 或 Ctrl+Enter 或点击外部完成；**光标移回已渲染公式 → 重新进入源码编辑**；`$...$` 内联
- **表格**：Tab/Shift+Tab 单元格导航（末格 Tab 自动新增行）；Ctrl+Enter 当前行下方插行；右键菜单增删行列；拖拽行/列边缘排序；冒号对齐 `:---`；表格工具条（行数列数、对齐、删除）

### 5. 任务列表
- `- [ ]` / `- [x]`（任意完成字符）；**渲染后点击 checkbox 直接切换状态**（Typora/Obsidian 均支持）

### 6. 快捷键体系（Windows）
| 快捷键 | 行为 |
|---|---|
| Ctrl+B / Ctrl+I / Ctrl+U / Ctrl+Shift+S / Ctrl+E | 粗体 / 斜体 / 下划线 / 删除线 / 行内代码 |
| Ctrl+1..6 / Ctrl+0 | 标题级别 / 普通段落 |
| Ctrl+K | 链接 |
| Ctrl+Shift+K / Ctrl+Shift+M / Ctrl+T | 代码块 / 公式块 / 表格 |
| Ctrl+Shift+Q | 引用块 |
| Ctrl+Shift+[ / ] | 无序 / 有序列表 |
| Ctrl+/ | 源码 ↔ 渲染切换 |
| Ctrl+P | 命令面板（Obsidian） |
| Alt+点击 / Shift+Alt 拖拽 | 多光标 / 矩形选择（Obsidian） |

### 7. 其他交互
- **浮动工具条**：选中文本即弹出（加粗/斜体/删除线/代码/链接/公式/颜色）
- **折叠**：标题/列表折叠（Obsidian Fold more/less）
- **Emoji 自动补全**：`:` 触发
- **块操作**（Notion 特有，可选）：悬停手柄拖拽排序、`/` 斜杠命令、块菜单转换

## 三、差异点（按需取舍）

| 特性 | Typora | Obsidian | Notion | 便签场景取舍 |
|---|---|---|---|---|
| 底层实现 | 自研渲染编辑 | CodeMirror 6 + decoration | 自研块模型 | 选 CM6（可复刻 Obsidian Live Preview） |
| 源码模式 | Ctrl+/ 切换 | 双模式 | 无（所见即所得） | 已有 Markdown 模式（textarea），保留 |
| 斜杠命令 | 无 | 无 | 有 | 已有 slash 命令（20 条），可保留 |
| 块拖拽 | 无 | 无 | 有 | 跳过（文本流模型） |
| 命令面板 | 无 | 有 | 无 | 可选 |
| 多光标 | 无 | 有 | 无 | 可选（CM6 内置） |
| 聚焦/打字机 | 有 | 无 | 无 | 可选 |

## 四、对 oii_sticker 的结论

- **技术路线**：即时预览编辑器用 **CodeMirror 6**（Obsidian Live Preview 同款内核）替代当前
  contenteditable 方案——contenteditable 无法实现"光标穿越标记、元素展开、自动转换、表格导航"
  等核心细节，CM6 的 decoration + 状态机是成熟路径。
- **复刻范围**（便签场景裁剪）：行内标记渲染与光标穿越、块级自动转换、回车/Tab/退格行为、
  代码块/公式块/表格（渲染 + 编辑 + 右键菜单）、任务点击切换、快捷键、自动配对、
  浮动工具条、语法高亮（markdown-it + hljs + mathjax 沿用）。
  跳过：文件系统相关（大纲/文件树/搜索/导出）、块模型（Notion 拖拽）、云同步。
- **分阶段执行**（见 docs/plan/phase-8-live-editor.md）。
